# Sprint 1 Checklist

Источник: `docs/sprint-1-plan.md`.

## 1) Подготовка

- [ ] Получить боевые Excel: бюджет, договоры, обязательства (или явно зафиксировать, каких файлов нет).
- [ ] Назначить, кто утверждает маппинг колонок.
- [ ] Выбрать embeddings/LLM endpoint (черновик: LM Studio).

## 2) Каркас репозитория

- [ ] Создать `ingest/`, `mcp_server/`, `assistant/`, `embed_svc/`, `deploy/`, `data/`, `configs/`.
- [ ] Создать `data/incoming/`, `data/rejects/`, `data/mappings/`.
- [ ] Добавить `.gitignore` (`.env`, xlsx incoming, venv).
- [ ] Заготовка Python-пакета `ingest`.
- [ ] Заготовка Go-модуля `mcp_server`.
- [ ] Заготовка пакета `assistant`.

## 3) Qdrant и конфиг

- [ ] Описать `deploy/docker-compose.yml` с Qdrant и volume.
- [ ] Добавить healthcheck Qdrant.
- [ ] Проверить `docker compose up` → сервис ready.
- [ ] Добавить `.env.example`.
- [ ] Добавить `configs/default.yaml` (коллекции, epsilon `0.01`, лимиты search).

## 4) Разбор Excel

- [ ] Описать листы и строку шапки бюджета.
- [ ] Описать иерархию 1…5: родители vs листья на примерах строк.
- [ ] Описать листы и шапку договоров.
- [ ] Описать листы и шапку обязательств.
- [ ] Зафиксировать источник правды по лимиту / факту / принятым / `remain_free`.

## 5) Маппинги

- [ ] Написать `data/mappings/budget.yaml`.
- [ ] Написать `data/mappings/contracts.yaml`.
- [ ] Написать `data/mappings/obligations.yaml`.
- [ ] Описать обязательные поля и rejects-условия.
- [ ] Описать нормализацию `contract_number`.
- [ ] Описать правила объединённых ячеек / двустрочной шапки / итогов.

## 6) Решения этапа 1

- [ ] Листы — источник правды.
- [ ] Провайдер эмбеддингов и размер вектора.
- [ ] stdio MCP в Cursor сразу или только HTTP.
- [ ] Оператор загрузки и частота обновления.
- [ ] Имена колонок факта / принятых / остатка и статусы обязательств.

## 7) Документация

- [ ] `data/mappings/README.md`.
- [ ] Поправки в `ARCHITECTURE.md` / `FUNCTIONALITY.md`, если канон уточнили.
- [ ] В README — как поднять Qdrant.

## 8) Критерии готовности (DoD)

- [ ] Qdrant поднимается с нуля, healthcheck зелёный.
- [ ] Есть YAML на каждый согласованный тип файла.
- [ ] Иерархия бюджета описана на реальных строках.
- [ ] Протокол решений заполнен.
- [ ] Боевые xlsx и секреты не в git.

## 9) Демо

- [ ] Показать Qdrant ready.
- [ ] Показать три маппинга и пример «родитель / лист».
- [ ] Показать колонки остатка, факта, принятых.
- [ ] Зафиксировать known limitations Sprint 1 (если появятся).
